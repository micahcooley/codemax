# Source and dependency notice

Codemax is an independent desktop project built around a Svelte interface, a thin Tauri host, and a Zag backend. No new public license grant is asserted over the user's uploaded masterplan or project materials. `license` metadata in package manifests is descriptive tooling metadata and must be reviewed/selected by the repository owner before public distribution.

No compiler binary, third-party npm/Cargo dependencies, font binaries, browser profiles, live API keys or provider credentials are bundled. The generated icon and fixture website are application/test assets. Runtime/compiler primitive declaration names reference the user's pinned Zag toolchain. Review third-party licenses when resolving dependencies and distributing native packages.
